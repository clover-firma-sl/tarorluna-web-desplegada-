TAROT LUNA - SUBIDA DESDE CHROMEBOOK A GITHUB Y VERCEL

1. Descarga y descomprime Tarot_Luna_COMPLETA_PRUEBA_VERCEL.zip.
2. Abre la carpeta tarot-luna-vercel.
3. Sube TODO lo que hay dentro a la raiz de un repositorio nuevo de GitHub.
   package.json debe verse directamente en la portada del repositorio.
4. No subas el ZIP al repositorio y no cambies los nombres ni las carpetas.
5. En Vercel: Add New > Project > Importa el repositorio.
6. Framework Preset: Next.js. Root Directory: ./
7. Deja Build, Install y Output con sus valores automaticos y pulsa Deploy.

PARA ACTIVAR LA AGENDA EN LA PRUEBA

1. Crea un proyecto en Supabase.
2. Abre SQL Editor, pega supabase-schema.sql y ejecutalo una sola vez.
3. En Vercel > Project > Settings > Environment Variables anade:
   SUPABASE_URL
   SUPABASE_SERVICE_ROLE_KEY
4. Vuelve a desplegar desde Deployments > Redeploy.
